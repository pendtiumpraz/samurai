# SPRINGLAKE SUMMARECON — Premium Lake Living Landing Page

## Project Overview
Create a world-class scrolling animated landing page for Springlake Summarecon — a premium residential development with a large lake in Summarecon Bekasi, Indonesia. Target audience: affluent Indonesian families seeking luxury lakeside living.

### Key Design Requirements

1. **Scroll-Controlled Video**: Each section uses the frame-by-frame scroll technique. Frames extracted at 10fps from Seedance 2.0 (10s = 100 frames per section).

2. **Zoom In/Out Effects**: Camera movements should be extreme — fast zooms, dramatic swoops, portal transitions.

3. **Text Syncing**: Text paragraphs and headlines should fade in/out at specific scroll positions within each section, not all at once.

4. **Buttons & Elements**: CTA buttons, navigation dots, animated decorative elements should appear at precise scroll positions with smooth animations.

5. **Interconnected Sections**: Each video section should feel like it naturally continues from the previous one (visual continuity).

6. **Elegant Design**: 
   - Color palette: Gold (#d4a853), Teal (#0d9488), Navy (#0a0a1a), Warm cream (#f5f0e8)
   - Fonts: Playfair Display (headings), Inter (body)
   - Subtle particle/ambient effects
   - Minimalist, premium feel

7. **Psychological Scroll Effect**: The scroll itself should feel like a cinematic journey — with varying scroll speeds (fast sections for energy, slow sections for serenity).

### Execution Steps

#### STEP 1: Research
- Search the web for "Springlake Summarecon Bekasi" to understand the project
- Look for visual references, key selling points, location details
- Document findings in storyboard/research.md

#### STEP 2: Generate Reference Images (GPT Image 2)
Use modelslab-generate.sh to create 5-10 reference/storyboard images:
- `bash springlake/scripts/modelslab-generate.sh --prompt "..." --ratio 16:9`
- Create images for: hero lake view, modern home interior, family promenade, sports facilities, night scene
- Save to springlake/storyboard/

#### STEP 3: Generate Videos (Seedance 2.0 Mini)
Use modelslab-video.sh for each of the 10 sections:
- `bash springlake/scripts/modelslab-video.sh --prompt "..." --duration 10 --ratio 16:9 --resolution 480p`
- Generate cinematic prompts with detailed camera movement descriptions
- Save videos to springlake/ as source reference

#### STEP 4: Convert Videos to Frame Sequences
For each generated video, extract frames:
- `ffmpeg -i <video.mp4> -vf "fps=10" -q:v 60 frames/section01_%04d.jpg`

#### STEP 5: Build index.html
Create a single-page HTML with:
- 10 scroll-controlled sections, each 300vh tall
- Sticky frame viewer per section
- Text appearing at specific scroll percentages
- Smooth transitions between sections
- Navigation dots
- CTA buttons
- Responsive design
- Preloading for smooth playback
- All styles inline (no external dependencies except Google Fonts)

#### STEP 6: Create skill.md
Document the complete workflow as a reusable skill file.

#### STEP 7: Create progress.md
Track what's done and pending.

#### STEP 8: Push to GitHub
```bash
git add springlake/
git commit -m "feat: Springlake Summarecon landing page"
git push origin main
```

## Claude Code Instructions
- When calling modelslab scripts, ALWAYS use full path: `bash springlake/scripts/modelslab-video.sh`
- Model ID for Seedance: `seedance-2-mini-t2v`
- Model ID for images: `gpt-image-2-t2i`
- API Key is in /etc/environment
- For video generation, pass --wait flag or use the polling pattern
- Video generation takes 30-120 seconds per video
- Image generation takes 20-60 seconds per image
- IMPORTANT: Images generated by GPT Image 2 are saved to /root/.openclaw/workspace/generate/ — copy them to springlake/storyboard/
- Videos generated by Seedance are saved to /root/.openclaw/workspace/generate/ — copy them to springlake/ directory
